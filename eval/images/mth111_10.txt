Function and Function Notation
A function is a relation where every input
has exactly one output
Function notation uses f(x) to represent the
output of a function for a given input
Example:
f(x) = 2x^2 + 3x - 5
f(2) = 2(2)^2 + 3(2) - 5 = 2(4) + 6 - 5
= 8+6 - 5 → f(2) = 9
Key concepts:
Domain: All possible input values
Range: All possible output values
Vertical Line test: A graph represents a function
if no vertical line intersects it more then once
Composition: f(g(x)) means putting one function
inside another
When evaluating a function, substitute the input
everywhere you see the variable
